## Instalação e execução local

Siga os passos abaixo para configurar o projeto localmente:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/seu-repositorio.git

2. **Instale as dependências: Com o npm instalado na sua máquina, execute:**
   ```bash
   npm install

2. **Execute o comando para monitorar alterações nos arquivos do projeto e recompilá-los automaticamente:**
   ```bash
   npm run dev

3. **Crie um arquivo .env e adicione a variável de ambiente para a conexão com o MongoDB**
   ```bash
   CONNECTIONSTRING=

3. **Inicie o projeto: Após as dependências serem instaladas, inicie o projeto com:**
   ```bash
   npm start
